コンテナ図とコンポーネント図

このページの説明

C4 モデルの2段目と3段目。点線の大きな枠がコンテナ（python3 で動かす単位と、import される部品の置き場）、中の箱がコンポーネント（ファイルや関数のまとまり）。 いちばん大事な境目は、ディーラーとプレイヤーをつなぐ 7つの命令（start_turn・place_bet・receive_hand・look_dealer_hand・input・finish_dealer_hand・notify_result）。この形を変えると、players/ の全部のファイルが動かなくなる。 1ラウンドの流れは左の dealer.py の箱に1回だけ書いた。autodealer.py の game() はその流れを関数に入れたもので、箱には違う所（±）だけを書いてある（点線の枠の行が「dealer.py と同じ」）。ルールを直すときは、同じ流れが2つのファイルにあるので両方を直す。行を押すとそのコードが出る。右端に ◯ がある行は環状線に駅があり、「環状線で見る」で3段目に下りられる。

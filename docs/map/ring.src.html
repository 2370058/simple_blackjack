コンテキスト図

C4 モデルの1段目。simple_blackjack 全体を1つの箱にして、周りの人と外部のものとのやりとりだけを描く。授業の3つのタスク（A 分析・B 戦略・C 改造）をする人も、ここでは別の人として並べる。箱や矢印を押すと、下に説明が出る。

コンテナ図とコンポーネント図

C4 モデルの2段目と3段目。点線の大きな枠がコンテナ（python3 で動かす単位と、import される部品の置き場）、中の箱がコンポーネント（ファイルや関数のまとまり）。 いちばん大事な境目は、ディーラーとプレイヤーをつなぐ 7つの命令（start_turn・place_bet・receive_hand・look_dealer_hand・input・finish_dealer_hand・notify_result）。この形を変えると、players/ の全部のファイルが動かなくなる。 同じ1ラウンドの流れが dealer.py と autodealer.py の game() の2か所に書いてあるので、ルールを直すときは両方を直す。行を押すとそのコードが出る。右端に ◯ がある行は環状線に駅があり、「環状線で見る」で3段目に下りられる。
